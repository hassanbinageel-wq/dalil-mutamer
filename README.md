# 🕋 دليل المعتمر · Dalil al-Mu'tamir

تطبيق أندرويد بواجهة عربية يرافق المعتمر أثناء الطواف والسعي، ويعدّ الأشواط **تلقائياً** بواسطة GPS، ويعرض الأدعية حسب موقعك، ويتضمّن **بروفايل معتمر كامل** (البيانات، الفندق، المشرف، الفيزا) و**محاكاة ثلاثية الأبعاد** للطواف والسعي، مع **تنبيه الهرولة** بين الميلين الأخضرين للرجال.

**تصميم وتطوير:** حسن جمال الليل · `hsn.pmt`

---

## ⚡ الحصول على APK

هذا المشروع يبني نفسه على GitHub. ما تحتاج Android Studio.

1. أنشئ مستودع على [github.com/new](https://github.com/new) باسم `dalil-mutamer` (Public)
2. من مجلد المشروع نفّذ:
   ```bash
   git init && git add . && git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/dalil-mutamer.git
   git push -u origin main
   ```
3. تبويب **Actions** → انتظر ✅ (~5 دقائق)
4. حمّل `dalil-mutamer-apk` من الـ Artifacts، فك الضغط، ثبّته على جوالك
5. للإصدارات: `git tag v2.1.0 && git push origin v2.1.0` → Release تلقائي

## ✨ الميزات

### 🏛️ الطواف — كل شيء تلقائي
- **محاكاة 3D** — مكعب الكعبة في المنظور الجوي مع نقطة تمثل موقعك تدور حوله
- **7 مناطق ذكية** حول الكعبة — الدعاء يتبدّل عند دخول كل منطقة:
  - الحجر الأسود → دعاء بداية الشوط
  - باب الكعبة → «اللَّهُمَّ إِنَّ الْبَيْتَ بَيْتُكَ...»
  - الركن العراقي → دعاء الركن
  - الميزاب وحجر إسماعيل → «اللَّهُمَّ أَظِلَّنِي فِي ظِلِّكَ...»
  - بين الركنين الشامي واليماني → «رَبَّنَا آتِنَا فِي الدُّنْيَا حَسَنَةً...»
  - الركن اليماني → «اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الشِّرْكِ...»
  - قرب إتمام الشوط → دعاء ختم الشوط
- الشوط يُحسب تلقائياً عند إتمام دورة كاملة (Debounce 45 ثانية)
- عند الشوط ٧ → دعاء ما بعد الطواف + رسالة تهنئة

### 🏔️ السعي — تلقائي مع تنبيه الهرولة
- **محاكاة 3D** — الصفا والمروة كجبلين مع النقطة تمثل موقعك على المسار
- الدعاء يتبدّل مع كل شوط:
  - الشوط الأول → التكبير والنية على الصفا + دعاء الشوط
  - الأشواط الفردية (٣، ٥، ٧) → دعاء التوجه للمروة
  - الأشواط الزوجية (٢، ٤، ٦) → دعاء التوجه للصفا
- **تنبيه الهرولة (للرجال فقط)** — عند دخول منطقة الميلين الأخضرين:
  - اهتزاز قوي
  - إشعار "🏃 اسرع الخطى"
  - المسار يتوهج أخضر مع نبض متحرك
  - يظهر دعاء الهرولة تلقائياً «رَبِّ اغْفِرْ وَارْحَمْ...»
- عند الشوط ٧ → دعاء ختم السعي

### 👤 بيانات المعتمر (يُكمَل عند أول تشغيل)
- الاسم الكامل، الدولة، رقم الهاتف
- الجنس (يفعّل تنبيه الهرولة تلقائياً للرجال)
- اسم المشرف ورقم هاتفه
- اسم الفندق
- موقع الفندق (يُحفظ بضغطة واحدة عبر GPS)
- رفع الفيزا (صورة أو PDF، حد ٤ ميغا)
- كل البيانات محفوظة **محلياً** على الجهاز، بدون إرسال لأي خادم

### 🎨 التصميم
- ثيم زمردي فاخر بوضعين: فاتح (أبيض + زمردي) وداكن (أسود + زمردي)
- تبديل تلقائي حسب إعدادات النظام
- خطوط: Tajawal للواجهة، Amiri للأدعية
- موشن احترافي في كل مكان (splash، counter، dua transitions، confetti)
- تحية حسب وقت اليوم

## 🎛️ ثوابت قابلة للتعديل

في `www/js/tawaf.js`:
- `KAABA_RADIUS_M = 45` — نصف قطر منطقة المطاف
- `MIN_ROUND_SECS = 45` — الحد الأدنى لمدة الشوط
- `getTawafZone(bearing)` — حدود المناطق حول الكعبة بالدرجات

في `www/js/sai.js`:
- `ARRIVAL_M = 25` — مسافة الوصول للصفا/المروة
- `MIN_LEG_SECS = 60` — الحد الأدنى لمدة شوط السعي

في `www/js/geo.js`:
- إحداثيات الكعبة، الصفا، المروة، والميلين الأخضرين
- `GREEN_ZONE_PCT = { start: 0.42, end: 0.62 }` — منطقة الهرولة (٤٢-٦٢٪ من مسار الصفا→المروة)

## 🔧 تعديل التطبيق

**تغيير الشعار:** استبدل `resources/icon.png` (1024×1024 PNG) وادفع — الـ workflow يعيد توليد كل الأحجام.

**تغيير اسم التطبيق:** عدّل `appName` في `capacitor.config.json`.

**تغيير الألوان:** `www/css/style.css` → متغيرات `:root`.

**اختبار محلي:**
```bash
cd www && python3 -m http.server 8080
```
افتح `http://localhost:8080` (لازم سيرفر — `file://` ما يدعم ES modules).
